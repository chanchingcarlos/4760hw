Q1 · Transition probabilities Chapman–Kolmogorov

State space S = {1,2,3}. Read the one-step transition matrix from the transition diagram on page 16 of Lecture Notes 2:

Black solid lines: 1↔2 and self-loops; blue dashed lines: 3→1 (0.3), 3→2 (0.2); each row sums to 1.

(a) Idea:Two-step probability P(X₂=2|X₀=1) = (P²)₁₂ = Σₖ p₁ₖ·pₖ₂. Sum over all intermediate paths (“where to go first + then to 2”) (total probability + Markov property).
Answer: P(X₂=2|X₀=1) = 0.4×0.5 + 0.5×0.3 + 0.1×0.2 = 0.37
(b) Idea:Joint probability = initial distribution × product of one-step transitions: P(X₀=2)·p₂₃·p₃₁·p₁₂ = 0.5×0.4×0.3×0.5 = 0.03。
Answer: 0.03

(a) Why re-normalize?Each row of the raw table has an NR (withdrawn) column. We only care about firms that remain rated, so condition on not NR: drop the NR column and divide each row by (100 − NR). Q3 · Gambler’s ruin Absorbing + irreducible

(a) Why is it Markov? Let Xₙ be the fortune after n plays. The next play is independent of the past: +1 with probability p, −1 with probability 1−p. Hence P(Xₙ₊₁ | X₀…Xₙ) = P(Xₙ₊₁ | Xₙ), which depends only on the current fortune — the Markov property. State space {0,1,…,N}; 0 and N are absorbing (stop playing).
Transition matrix: p₀₀=1, pN,N=1; for 0<i<N, pi,i+1=p, pi,i−1=1−p, 0 otherwise.
(b) Irreducible? No. 0 and N can never be left: 1 can reach 0 but 0 cannot reach 1, so 0 and 1 do not communicate → more than one communicating class.
(b) No. States 0 and N are absorbing and do not communicate with the others.
(c) Stationary distribution?A finite chain always has one; but without irreducibility it is not unique. E.g. δ₀ (forever at 0) and δN are both stationary, as is any convex combination of them.
(c) Exists but is not unique.

Q4 · (s,S) ordering policy Inventory Markov chain

Intuition: Xₙ is the end-of-period-n inventory. Given beginning inventory Xₙ₋₁, the ordering rule is a deterministic function: Yₙ = Xₙ₋₁(if ≥s), Yₙ = S (if <s); subtract the period’s independent demand Dₙ (lost sales: Xₙ = max(Yₙ−Dₙ, 0)). Because Dₙ is i.i.d. and independent of the history, the distribution of Xₙ given Xₙ₋₁ no longer depends on earlier history → Markov. State space {0,…,S}。
Transition probabilities (αk=P(D=k)）：
i ≥ s：pi,j=αi−j(1≤j≤i), pi,0=Σk≥iαk, 0 for j>i.
i < s：pi,j=αS−j(1≤j≤S), pi,0=Σk≥Sαk (independent of i).

Try it: (s,S) inventory simulation

Shape of the transition matrix: The first s rows (i=0…s−1) are identical; each row below is a shifted α vector with the tail summed into 0. Try changing s and S to see how the “reorder line” pulls low inventory back up to S.

Q6 · Random walk on a weighted undirected graph Detailed Balance

Why irreducible? The graph is connected, so any x,y are joined by a path x=v₀→v₁→…→vₙ=y; each hop goes to a neighbor so its one-step probability is >0 (positive weights), and the whole path has probability = product >0, so y is accessible from x; the reverse holds too (undirected) ⇒ all states communicate ⇒ irreducible (a single class).
How to guess the stationary distribution?Intuition: long-run time at a node is proportional to its “weighted degree” w(x)=Σ_{z∈N(x)} w({x,z}). Let W=Σₓ w(x), πₓ = w(x)/W. Verify detailed balance: πₓpₓᵧ = w(x)/W · w({x,y})/w(x) = w({x,y})/W = πᵧpᵧₓ; summing over x gives πᵀ=πᵀP. If V is finite, W is finite and π is a proper distribution; if infinite, it is an invariant measure.
Answer: Irreducible (Yes). πx = w(x)/W, where w(x)=Σz∈N(x)w({x,z}), W=Σvw(v).
