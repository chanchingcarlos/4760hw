Q1 · 轉移概率計算 Chapman–Kolmogorov

狀態空間 S = {1,2,3}。由 Lecture Notes 2 第 16 頁轉移圖讀出一步轉移矩陣：

→ 1→ 2→ 3

20.30.30.4
30.30.20.5

實線黑色：1↔2 及自圈；藍色虛線：3→1 (0.3)、3→2 (0.2)；留意每行和 = 1。

(a) 概念：兩步概率 P(X₂=2|X₀=1) = (P²)₁₂ = Σₖ p₁ₖ·pₖ₂。即係「第一步去邊＋第二步去 2」所有中間路徑加總（全概率＋Markov 性）。
答案：P(X₂=2|X₀=1) = 0.4×0.5 + 0.5×0.3 + 0.1×0.2 = 0.37
(b) 概念：聯合概率 = 初始分布 × 連乘一步轉移：P(X₀=2)·p₂₃·p₃₁·p₁₂ = 0.5×0.4×0.3×0.5 = 0.03。
答案：0.03

Q2 · 信貸評級轉移矩陣 條件化＋多步

(a) 點解要 re-normalize？原表每行有 NR（撤回評級）一欄。我哋只關心「繼續有評級」嘅公司，所以要 condition on 唔係 NR：將 NR 欄刪除，再將每行除以（100 − NR）。數學上即 p̃ᵢⱼ = pᵢⱼ / (1 − pᵢ,NR)。例如 AAA 行：分母 = 100−3.08 = 96.92，AAA→AAA = 87.28/96.92 = 0.900537。

Q3 · 賭徒破產 吸收態＋不可約

(a) 點解係 Markov？設 Xₙ 為第 n 局後嘅資金。下一局獨立於過去：贏就 +1（概率 p），輸就 −1（概率 1−p）。所以 P(Xₙ₊₁ | X₀…Xₙ) = P(Xₙ₊₁ | Xₙ)，只依賴而家嘅資金，符合 Markov 性。狀態空間 {0,1,…,N}，0 同 N 係吸收態（停玩）。
轉移矩陣：p₀₀=1，pN,N=1；0<i<N 時 pi,i+1=p，pi,i−1=1−p，其餘 0。
(b) Irreducible？否。 0 同 N 出唔返嚟：由 1 可以去 0，但由 0 去唔到 1，所以 0 同 1 唔互通 → 多過一個互通類。
(b) 否（No）。0、N 吸收，唔同其他狀態互通。
(c) 平穩分布？有限狀態鏈必存在平穩分布；但因為唔 irreducible，唔唯一。例如 δ₀（永遠停喺 0）同 δN 都係平穩，佢哋嘅凸組合都係。
(c) 存在，但不唯一（Exists but not unique）。

Q4 · (s,S) 訂貨政策 存貨 Markov 鏈

直觀：Xₙ 係第 n 期期末存貨。 bekannten 期初存貨 Xₙ₋₁ 後，補貨規則係確定性函數：Yₙ = Xₙ₋₁（若 ≥s），Yₙ = S（若 <s）；再減去當期獨立需求 Dₙ（缺貨即棄：Xₙ = max(Yₙ−Dₙ, 0)）。因為 Dₙ i.i.d. 且獨立於歷史，Xₙ 在已知 Xₙ₋₁ 下嘅分布唔再依賴更早歷史 → Markov。狀態空間 {0,…,S}。
轉移概率（αk=P(D=k)）：
i ≥ s：pi,j=αi−j（1≤j≤i），pi,0=Σk≥iαk，j>i 時 0。
i < s：pi,j=αS−j（1≤j≤S），pi,0=Σk≥Sαk（與 i 無關）。

互動：(s,S) 存貨模擬

Q5 · PageRank 阻尼＋平穩

讀圖：5 個網頁嘅連結（out-degree）：1→{3,5}，2→{1,3}，3→{2,4}，4→{1,5}，5→{3}。所以 deg = (2,2,2,2,1)。

Q6 · 無向加權圖上隨機漫步 Detailed Balance

Irreducible 點嚟？圖連通 ⇒ 任兩點 x,y 之間有條路 x=v₀→v₁→…→vₙ=y，每步都係鄰居所以一步概率 >0（權重係正數），成條路概率 = 連乘 >0，所以 y 由 x 可達；無向圖反向亦然 ⇒ 任意兩態互通 ⇒ irreducible（得一個互通類）。
平穩分布點估？直覺：長期停留喺某點嘅時間正比於「加權度」w(x)=Σ_{z∈N(x)} w({x,z})。設 W=Σₓ w(x)，πₓ = w(x)/W。驗證 detailed balance：πₓpₓᵧ = w(x)/W · w({x,y})/w(x) = w({x,y})/W = πᵧpᵧₓ，兩邊對 x 求和即得 πᵀ=πᵀP。若 V 有限，W 有限，π 係合法分布；若無限，就係不變測度。
答案：Irreducible（Yes）。πx = w(x)/W，其中 w(x)=Σz∈N(x)w({x,z})，W=Σvw(v)。
